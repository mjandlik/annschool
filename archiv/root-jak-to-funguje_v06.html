1. Celkový obrázek

Celé řešení má tři části, které spolu mluví přes internet:

  • GitHub – úložiště souborů (kód, testy, materiály) a zároveň web zdarma (GitHub Pages).
  • Prohlížeč na tabletu – stránky se v něm spouštějí. Veškerá „logika“ (vyhodnocení, kreslení, ukládání rozpracovaného testu) běží tady v JavaScriptu.
  • Google – malý skript (Apps Script), který přijímá výsledky a zapisuje je do tabulky. To je jediná část, která umí ukládat.
Plná čára = posílání dat, čárkovaně = čtení. GitHub nic neukládá za běhu, ukládá jen Google.

2. GitHub a GitHub Pages

Repozitář

Git je systém na verze souborů: každá změna je „commit“ s popisem, kdo a co změnil, a jde se k ní kdykoli vrátit. GitHub je služba, kde repozitář (složka se soubory + celou historií) leží na internetu. Tenhle projekt je veřejný repozitář mjandlik/annschool:

GitHub Pages = web zdarma

V nastavení repozitáře (Settings → Pages) se zapne, že GitHub soubory z větve main zveřejní jako web: https://<uživatel>.github.io/<repozitář>/. Po každém git push se web do minuty aktualizuje.

Zásadní omezení: GitHub Pages je statický hosting. Server jen posílá soubory tak, jak leží. Nemá databázi, nespustí žádný kód na serveru a stránka do repozitáře nemůže nic zapsat (na to by potřebovala tajný klíč a ten nesmí být ve veřejném kódu – kdokoli by ho zkopíroval a mohl repozitář smazat). Proto je potřeba Google (kap. 4).

3. Co dělá Claude

Claude běží v cloudu Anthropicu a v tomhle projektu má „pracovní stůl“ s Linuxem, Pythonem, Node.js a připojeným repozitářem. Na požádání:

  • napíše kód – HTML, CSS, JavaScript, Apps Script; i celé stránky s grafikou (SVG) a vzorci (KaTeX),
  • vyzkouší ho – v Playwrightu (prohlížeč Chromium bez obrazovky ovládaný skriptem) otevře stránku jako iPad na výšku i na šířku, klikne na odpovědi, nakreslí myší čáru, udělá snímek obrazovky a zkontroluje, že nic nepadá; odesílání do Googlu při tom podvrhne, aby se do tabulky nezapisovaly testovací nesmysly,
  • zkontroluje se – před každým nahráním projde „kontrolu po sobě“: výsledky přepočítá nezávisle (často druhý agent, který úlohy nepsal), spustí kontrolu testu a kontrolu celého repozitáře a projde registr dřívějších chyb (system/Pouceni_vXX.md); novou chybu do registru zapíše, aby se neopakovala,
  • nahraje to – git commit + git push do repozitáře,
  • přečte výsledky – z adresy skriptu (?akce=data) nebo z tabulky přes Google Drive, a podle chyb navrhne další úlohy.

Co neumí: neběží pořád (jen když s ním někdo píše nebo má naplánovanou úlohu), nevidí tablet, nemůže za tebe kliknout v Google účtu (nasazení skriptu a povolení oprávnění dělá člověk) a nemá vlastní server.

4. Proč Google (Apps Script + tabulka)

Google Apps Script je JavaScript, který běží na serverech Googlu a je připojený k tabulce. Když se „nasadí jako webová aplikace“, dostane adresu https://script.google.com/macros/s/…/exec a umí odpovídat na požadavky z internetu – je to malý server zdarma:

function doPost(e) {               // stránka posílá výsledky
  const data = JSON.parse(e.postData.contents);
  SpreadsheetApp.getActiveSpreadsheet()
    .getSheetByName("Udalosti").appendRow([new Date(), data.x, data.y]);
  return ContentService.createTextOutput('{"ok":true}')
    .setMimeType(ContentService.MimeType.JSON);
}
function doGet(e) {                // přehled si čte data
  const rows = SpreadsheetApp.getActiveSpreadsheet()
    .getSheetByName("Udalosti").getDataRange().getValues();
  return ContentService.createTextOutput(JSON.stringify(rows))
    .setMimeType(ContentService.MimeType.JSON);
}
  • Proč to funguje bez klíče: skript běží „jako vlastník tabulky“ a přístup má „kdokoli“. Stránka zná jen adresu. Nejhorší, co může cizí člověk udělat, je poslat do tabulky nesmysl – nemůže nic smazat ani přečíst Google účet.
  • Tabulka jako databáze: list Udalosti (jeden řádek = jedna událost: start testu, pokus, nápověda, odchod do jiné aplikace…), list Zarizeni (náhodné ID tabletu → přezdívka, schválení), list Nahledy (poslední stav papíru u každého příkladu – test ho posílá každých 20 s, když se papír změnil, a přehled ho ukáže tlačítkem „papír teď“). list Stav (kde v testu dítě právě je a jak dlouho – test posílá polohu každých 20 s a při přechodu, odchodu a návratu; přehled se na ni ptá každých 20 s). Obrázky papíru jdou jako soubory na Disk; starší obrázek náhledu skript dá do koše.
  • CORS trik: prohlížeč posílá data jako Content-Type: text/plain. Takový „jednoduchý“ požadavek nepotřebuje předběžný dotaz (preflight), který Apps Script neumí.
  • Duplicity: každá událost má náhodné id; když stránka pošle něco dvakrát (výpadek sítě), skript to pozná a zahodí.

7. Recept: totéž pro vlastní projekt

  1. Účet a repozitář: na github.com založ účet a nový repozitář (Public). Pro hlavní web domény se hodí název <uživatel>.github.io, ale jde to s jakýmkoli.
  2. První stránka: do repozitáře nahraj index.html (stačí přes web GitHubu: Add file → Create new file).
  3. Zapni Pages: Settings → Pages → Source: Deploy from a branch, větev main, složka / (root). Za chvíli běží na https://<uživatel>.github.io/<repozitář>/.
  4. Potřebuješ ukládat data? Založ Google tabulku → Rozšíření → Apps Script → vlož doPost/doGet (viz kap. 4) → Nasadit → Webová aplikace (spustit jako: já, přístup: kdokoli) → zkopíruj adresu /exec.
  5. Ve stránce posílej data: 
    await fetch("https://script.google.com/macros/s/…/exec", {
  method: "POST",
  headers: { "Content-Type": "text/plain;charset=utf-8" },
  body: JSON.stringify({ x: "ahoj", y: 42 })
});
    Hotový modul s frontou a ID zařízení je v system/lib/zaznam.js, skript pro Google v system/Skript_vysledky_v04.gs – klidně je zkopíruj a uprav.
  6. Claude ti s tím pomůže: stačí popsat, co má stránka dělat. Když mu připojíš repozitář, kód rovnou napíše, otestuje a nahraje.
Tajné věci nikdy do veřejného repozitáře: hesla, API klíče, tokeny. Cokoli je v HTML/JS na webu, může si kdokoli přečíst (v prohlížeči „Zobrazit zdroj“).

8. Vlastní doména přes Cloudflare (marianjandl.com)

Doména koupená přes Cloudflare znamená, že Cloudflare spravuje její DNS – „telefonní seznam“, který k názvu domény říká, na jakou IP adresu (server) se má prohlížeč připojit. GitHub Pages se k vlastní doméně připojí takhle:

  1. Ověř doménu na GitHubu (ochrana proti tomu, aby ti ji někdo „unesl“): GitHub → tvůj profil → Settings → Pages → Add a domain. GitHub ukáže TXT záznam, ten přidej v Cloudflare (DNS → Records → Add record) a potvrď.
  2. V repozitáři: Settings → Pages → Custom domain: marianjandl.com → Save (do repozitáře se přidá soubor CNAME).
  3. V Cloudflare → DNS → Records přidej:
    TypNameObsahProxy
    A@185.199.108.153DNS only
    A@185.199.109.153DNS only
    A@185.199.110.153DNS only
    A@185.199.111.153DNS only
    CNAMEwww<uživatel>.github.io (bez názvu repozitáře)DNS only
    Volitelně i IPv6 (AAAA): 2606:50c0:8000::153, …8001::153, …8002::153, …8003::153.
  4. „DNS only“ (šedý mráček) nech aspoň do doby, než GitHub vystaví HTTPS certifikát – s oranžovým mráčkem (Cloudflare proxy) se to často zasekne. Případně pak proxy zapni a v Cloudflare nastav SSL/TLS na Full.
  5. Počkej (DNS se šíří až 24 hodin), pak v Settings → Pages zaškrtni Enforce HTTPS.
  6. Nepoužívej „wildcard“ záznam *.marianjandl.com – otevírá cestu k převzetí subdomén.

Adresy podle dokumentace GitHubu: Managing a custom domain for your GitHub Pages site. Před nastavením si je tam radši zkontroluj, mohou se změnit.

9. Alternativy a limity

MístoJde použítProč / proč ne
GitHub PagesCloudflare Pagestaké zdarma, napojí se přímo na GitHub repozitář a doménu máš už u Cloudflare – nastavení domény je pak na pár kliknutí
Google Apps Script + tabulkaCloudflare Workers + D1 (databáze) nebo KVrychlejší a „opravdovější“ server, ale víc programování a správy; tabulku si nikdo nepřečte tak snadno jako Google Sheets
Google Apps ScriptFirebase, Supabasedatabáze s přihlašováním; má smysl, když má mít každý uživatel vlastní účet
  • Limity Apps Scriptu: denní kvóty volání a doby běhu (pro rodinu bohatě stačí), odpověď trvá zlomky sekundy až sekundy, adresa je veřejná.
  • Žádné přihlašování: „kdo“ se pozná jen podle náhodného ID tabletu a přezdívky. Pro rodinu stačí, pro školu by to nestačilo.
  • localStorage patří jedné doméně v jednom prohlížeči; v anonymním okně nebo po smazání dat Safari zmizí.
